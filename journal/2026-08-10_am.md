# Daily Journal - 2026-08-10_am

## Challenges Faced
After turning on the server we found out our static configuration was not configured permanently.


## Today's Tasks
- Change DHCP ip into static permanently.
- Hardening of server


##What I did?
1) I deleted /etc/netplan/50-cloud-init.yaml and created  /etc/netplan/01-netcfg.yaml

2)new config inside /etc/netplan/01-netcfg.yaml

network:
  version: 2
  ethernets:
	enp0s7:
           dhcp4: false
	   addresses:
             - 192.168.1.100/24
	   routes:
             - to: default
	       via: 192.168.1.1
           nameservers:
	       addresses: [8.8.8.8, 1.1.1.1]	

3) I also created /etc/cloud/cloud.cfg.d/99-disable-network-config.cfg
  now add in file => network: {config: disabled}

4)This done because cloud.init auto creates file 50-cloud-init.yaml resets our static config and so that we override  cloud.init config in 
90-disable-network-config.cfg by 99-disable-network-config.cfg  in step 3 . 
We create our static config in 01-netcfg.yaml. files in netconfig dir are in alphabetical order so later will override.

5) we gave chmod 600 to /etc/netplan/01-netcfg.yaml  and  /etc/cloud/cloud.cfg.d/99-disable-network-config.cfg

6)then sudo netplan apply,apllies config

7)ping -c 4 google.com
